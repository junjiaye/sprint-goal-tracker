# 人力季度冲刺跟踪系统 · 高保真原型

2026 Q4 冲刺目标跟踪系统交互原型，目标卡按《四季度达标冲刺目标卡》官方 Word 模板实现。

## 在线访问

https://junjiaye.github.io/sprint-goal-tracker/

## 功能

- **达标冲刺目标卡**：按官方模板——"火力全开 决胜2026"主视觉 + 姓名/部门/序列 + 目标项与目标值（序号 1-4）+ 冲刺寄语；十大序列目标项统一口径（选择序列自动带出，含对照表）；一人一卡，**部门主管填写后直接下发到人，无需员工回签**；下发后盖章锁定不可修改，支持撤回；可导出 PNG / 打印 PDF
- **部门目标进度看板**：负责人填写部门目标（目标1/目标2/路径），每周更新进度；员工仅本部门只读
- **角色权限模拟**：员工 / 部门负责人 / BP 三身份切换演示
- 纯前端原型，数据存于浏览器 localStorage，侧边栏可一键重置
