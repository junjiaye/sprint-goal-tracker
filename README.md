# 人力季度冲刺跟踪系统 · 高保真原型

2026 Q4 冲刺目标跟踪系统交互原型：个人冲刺目标卡 + 部门目标进度看板 + BP 总览。

## 在线访问

https://junjiaye.github.io/sprint-goal-tracker/

## 功能

- **个人冲刺目标卡**：十大序列（实施/客开/客户成功/销售/售前/人力/财务/市场/销管/PMO），填写姓名、部门、员工编码、目标、路径，实时生成卡片预览；部门负责人一对一确认后锁定（盖章），不可修改；支持导出 PNG / 打印 PDF
- **部门目标进度看板**：负责人填写部门目标（目标1/目标2/路径），每周更新进度；员工仅本部门只读
- **角色权限模拟**：员工 / 部门负责人 / BP 三身份切换演示
- 纯前端原型，数据存于浏览器 localStorage，侧边栏可一键重置
